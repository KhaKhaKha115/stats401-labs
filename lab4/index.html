Lab 4: Cleaning Web Data for Visualization

How does COVID-19 tweet sentiment change by week?

Each bar shows the average RoBERTa sentiment score for tweets in one week.

Short Analysis

I used the COVID-19 Twitter Dataset from Kaggle, created by Arunava Chakraborty, which contains public COVID-19 tweets collected across multiple periods. I used three files covering April–June 2020, August–September 2020, and April–June 2021, then combined them and selected a reproducible sample of 1,000 tweets from each period, giving 3,000 tweets in total. Data source: COVID-19 Twitter Dataset on Kaggle

For cleaning, I removed records with missing tweet text or invalid dates, handled missing values, standardized text fields, and removed duplicate tweets. I did not use the sentiment labels already included in the original datasets. Instead, I calculated sentiment using the cardiffnlp/twitter-roberta-base-sentiment-latest model.

The sentiment score is the positive probability minus the negative probability, so more negative values indicate more negative sentiment. The visualization groups tweets by week and shows the average sentiment score for each week. Overall, sentiment remains negative across all sampled weeks. The most negative weeks appear around early June 2020 and early September 2020, while several weeks in 2021 are closer to neutral, suggesting that COVID-19 discussion became somewhat less negative in the later period.
