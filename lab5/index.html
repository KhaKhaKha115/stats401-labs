Lab 5: Transit Network

A synthetic transit system with 50 stations, 50 undirected connections, and five districts. A connection represents direct travel between two stations. Positions show network structure, not geography.

1. Node-link visualization

Drag stations to untangle connections. Hover or keyboard-focus a station to highlight its neighbors; hover a route for its travel time. Labels use station IDs (s7 = Station 7).

Node-link design

District is shown with node and label color, while station type is shown with shape: circles for local stations, squares for transfer stations, and triangles for terminals. Larger symbols represent stations with more passengers per day. Route type is shown by link color, and thicker links represent longer travel times. Users can drag nodes to reduce overlap, hover to highlight connected stations, and use tooltips to see exact values. The node positions come from the force-directed layout, so they do not represent real geographic locations.

2. Adjacency matrix

Rows and columns use the same station order. Colored cells show direct connections; darker cells mean longer travel (2–16 minutes). Pale cells mean no connection. Each undirected route appears twice.

Matrix design

Both rows and columns represent the same set of stations. By default, stations are grouped by district and then station number, which makes district-based patterns easier to see. Users can also reorder the matrix by station number or by station type and then station number to compare the network from different perspectives. Colored cells show direct connections, while paler cells indicate no connection. Cell color represents the route type, and darker shades show longer travel time. Since the network is undirected, each route appears twice in the matrix. Tooltips provide additional station and route information without crowding the display.

3. Network questions and findings

QuestionSupport / viewObservation and visual evidence
Which stations appear central?Partially · node-linkThe node-link diagram is useful for identifying stations that appear central because it shows the network topology and how stations are connected. Stations such as s18, s7, s4, and s31 appear relatively central because they are located within the main connected structure and have several nearby connections. However, this is only a visual observation because centrality is not directly encoded. Also, the force-directed node-link layout is non-deterministic, so node positions may change between runs even when the network data stays the same. Therefore, a station appearing near the center of the screen does not necessarily mean it has the highest network centrality.
Which districts are strongly connected?Well · matrixThe adjacency matrix is useful because stations are ordered first by district and then by station number, so the rows show the origin district and the columns show the destination district in grouped blocks. This makes directional connection patterns between districts easier to see. The strongest visible patterns are Central to North, North to South, South to East, East to West, and West to Central. In contrast, there are very few or no visible connections in the opposite or other directions, such as North to Central, South to Central, East to Central, Central to South, or Central to East. This directional pattern is easier to notice because the matrix is ordered by district.
Where are transfer and terminal stations?Well · node-linkStation type is encoded by shape, with circles for local stations, squares for transfer stations, and triangles for terminal stations. Transfer and terminal stations are spread across different parts of the network rather than being concentrated in one area. For example, terminal stations such as s31, s34, s37, and s40 appear in different parts of the topology, while transfer stations such as s35, s38, and s50 are also distributed throughout the network.
Which stations have high passenger volume?Well · node-linkPassenger volume is encoded by symbol area, so the stations with the largest symbols are the busiest. s49 and s43 stand out as some of the largest nodes in the diagram. Stations such as s40, s37, s50, and s45 also appear to have relatively high passenger volume because their symbols are noticeably larger than most others.
Where are the longest direct connections?Well · bothThe thickest links and darkest cells identify s7–s31 (16 minutes), s18–s34 (15), and s29–s50 (14); hover confirms values.
Are route types concentrated?Partially · bothRoute type is encoded by link color in the node-link diagram and cell color in the adjacency matrix. However, the three route colors appear to be distributed across many parts of the network rather than forming clear clusters. Metro, Express, and Shuttle routes all appear in several different regions of the topology, so there is no strong visual evidence that one route type is concentrated in only one part of the network. The matrix also shows the route colors scattered across different station groups rather than forming one clear block.
