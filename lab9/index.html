Lab 9: Geospatial Visualization with D3

Dataset Description

This visualization uses the provided 2025 nominal GDP dataset containing the 50 largest economies by nominal GDP. Each record includes an ISO-3 country identifier, country name, GDP in billions of current U.S. dollars, and GDP rank. The GDP data are based on the IMF World Economic Outlook, October 2025. Because some observations may include IMF staff estimates and can later be revised, the values should be interpreted as current estimates rather than permanent figures. Countries outside the top-50 dataset are shown as missing data rather than being assigned a GDP value of zero.

Design and Comparison

The choropleth and cartogram use the same GDP data, but they highlight different things. The choropleth keeps each country’s real location and shape, while color shows GDP. This makes it easier to see regional patterns and where larger or smaller economies are located. However, small countries can still be hard to notice even if their GDP is high.

The cartogram focuses more directly on economic size. Countries with larger GDP become bigger, while countries with smaller GDP shrink. This makes major economies such as the United States and China stand out more clearly. The trade-off is that country shapes and sizes are distorted, so some places become harder to recognize. Linked highlighting helps users match the same country across both maps.

Overall, the choropleth is better for understanding geographic patterns, while the cartogram is better for comparing economic magnitude. Using both views together gives a clearer picture of both location and relative economic size.
