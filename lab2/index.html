Lab 2 - Multivariate Visualization with D3

This visualization explores the relationship among population, temperature, region, and development level.

Design Justification

Temperature → X-axis: I mapped temperature to the x-axis because it is a numerical variable and position makes it easy to compare values from low to high. This also helps viewers notice whether warmer or cooler cities tend to have different population levels.

Population → Y-axis: I mapped population to the y-axis because it is also numerical, so position is a clear way to compare city populations. Together with temperature on the x-axis, viewers can easily see the relationship between these two variables.

Development Level → Color: I used color to represent development level. Low, Medium, and High use progressively darker shades of the same color so the ordered difference is easy to understand. I hope viewers can notice whether highly developed cities appear in particular parts of the chart.

Region → Letter inside each point: I used N, S, E, and W inside each data point to represent North, South, East, and West. This keeps every point the same shape while still making region easy to identify. Viewers can compare whether cities from the same region show similar patterns.
